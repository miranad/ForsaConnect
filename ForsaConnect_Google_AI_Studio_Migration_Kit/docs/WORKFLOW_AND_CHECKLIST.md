# Handover and acceptance checklist

## Phase A: baseline
[ ] Imported the **actual Claude V3 code** OR explicitly chose reconstructed starter.
[ ] React web preview loads with no errors.
[ ] Navbar, Arabic RTL typography, icon/logo, responsive view at 360/390/768/1440px.
[ ] ForsaConnect spelled exactly; no references to OpenWay or previous names.

## Phase B: researched opportunities
[ ] 25 distinct IDs; 17/3/5 geography counts.
[ ] 25 official URLs rendered, no invented link replacements.
[ ] Each listing includes original source, eligibility, deadlines / event date, costs, organizer.
[ ] Text is Arabic; controls are accessible and filters work together.
[ ] No stale listing presented as guaranteed open. Check two deadlines on Oct 31, 2026.
[ ] Instagram-post content not claimed to be extracted: original two Instagram posts could not be accessed in research.

## Phase C: backend
[ ] Firebase project provisioned with user's consent.
[ ] Auth works and admin roles enforced by Firebase rules/server checks.
[ ] Public read only approved records. Anonymous submissions pending and cannot self-approve.
[ ] Cross-device persistence validated; no local-only 'success' masquerading as submitted.
[ ] Spam prevention, link validation, privacy disclosure, deletion policy and access rules reviewed.

## Phase D: publish
[ ] Site tested on Android and desktop; WCAG contrast/accessibility checked.
[ ] Hosting costs, quotas and public URL reviewed.
[ ] Domain/contact/organization authority established before advertising partnerships.
[ ] Cloud Run deployment approved explicitly; verify resulting public link.
